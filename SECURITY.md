# Reporting a security problem

If you think you've found a security problem in one of these packages, please don't open a public issue. Email **hello@daptgroup.com** with "Security" in the subject, and include:

- the package name and version (shown in the web part's settings, under **About**);
- what you found and how to reproduce it;
- any proof-of-concept, if you have one.

We'll acknowledge your report within three working days and keep you updated while we fix it. When a fix is ready, we publish a new release and note it in the gift's version history.

## Supported versions

Only the latest release of each gift receives fixes. Please update to it before reporting.
